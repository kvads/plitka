# Implementation Plan: Мобильное редактирование плана

**Branch**: `002-mobile-canvas-editing` | **Date**: 2026-10-13 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-mobile-canvas-editing/spec.md`

## Summary

Расширить существующий SVG редактор: два пальца меняют центр и масштаб при любом инструменте, не сдвигая выбранную раскладку; сенсорное добавление и перемещение вершины показывают временную позицию и выполняют команду геометрии лишь после подтверждения. Успешно сохранённая точка совпадает с маркером, отклонённое перемещение показывает ошибку и сохраняет прежний граф. Мобильные панели остаются доступными от 320 px без прокрутки документа. Мышь, клавиатура, команды геометрии и формат проекта сохраняются.

## Technical Context

**Language/Version**: TypeScript ~5.9.3, React ^19.2.0; существующий Python/FastAPI backend без изменений.

**Primary Dependencies**: React, SVG, Pointer Events, DOMPoint, существующие `snap` и `blockingVertices`. Новые пакеты не нужны.

**Storage**: текущий `ProjectDocumentV3` в localStorage. Сохраняются только подтверждённая геометрия и `viewport`; предпросмотры остаются в памяти компонента. Формат JSON проекта не меняется.

**Testing**: Playwright Chromium с сенсорным профилем и адресные регрессии мыши/клавиатуры; `npm --prefix frontend run build`.

**Target Platform**: мобильный браузер с Pointer Events, ширина от 320 px, портретная и альбомная ориентация; настольный браузер с мышью/клавиатурой.

**Project Type**: существующее веб приложение React + FastAPI.

**Performance Goals**: вид обновляется в ходе движения двух пальцев, геометрия не сохраняется до подтверждения. Пользовательские метрики заданы SC-001–SC-005; числовой бюджет кадра не задан.

**Constraints**: масштаб 0,2–8; координаты учитывают размер SVG и открытые панели; привязка к сетке и зона безопасности вершин сохраняются; жест не вызывает команду геометрии; документ не получает горизонтальную прокрутку.

**Scale/Scope**: один открытый проект и одно активное полотно. Новые API, схема хранения, совместная работа и изменение алгоритма геометрии не входят в объём.

## Phase 0: Research

[research.md](research.md) фиксирует выбор модели жестов, преобразования координат, подтверждения правок, зоны безопасности и мобильной компоновки. Все вопросы технического контекста разрешены без новых зависимостей.

## Phase 1: Design & Contracts

[data-model.md](data-model.md) описывает сохранённый вид и временные состояния с переходами. [mobile-canvas-ui.md](contracts/mobile-canvas-ui.md) задаёт наблюдаемое поведение сенсорного ввода, мыши и клавиатуры. [quickstart.md](quickstart.md) содержит сценарии M01–M06 для проверки.

В рабочем дереве уже есть первая реализация жестов, подтверждения и мобильных панелей с адресными тестами. При генерации задач оставшуюся работу нужно выделить отдельно: видимость конечной точки при перетаскивании, ошибка после отказа подтверждённой команды перемещения, серия из 10 жестов, все инструменты и альбомная ориентация. Это проектные риски и пробелы проверки, а не новые требования к формату проекта.

### Последовательность последующей реализации

1. Разделить одиночное касание, жест двумя пальцами и временное размещение. Второй палец отменяет одиночное действие до любой команды геометрии.
2. Вычислять масштаб вокруг середины пальцев и центр вида в координатах SVG; ограничить масштаб и сохранить текущую сетку.
3. Показывать временную точку добавления или перемещения с координатами; выполнять прежнюю команду только по подтверждению. Очищать временное состояние при отмене, смене инструмента, потере касания и начале жеста.
4. Оставить предпросмотр перемещения различимым при пальце на точке; после отказа подтверждённой команды показать ошибку без изменения графа. Предварительную проверку всех ограничений графа не обещать.
5. Сделать инструменты и нижние действия независимо прокручиваемыми, оставить минимум 44 px для сенсорных кнопок и не расширять страницу.
6. Проверить мобильные сценарии, адресные регрессии мыши/клавиатуры, импорт/экспорт и сборку. Добавить проверку двухпальцевого жеста при каждом инструменте и неизменности смещения раскладки, повторных жестов и альбомной ориентации. Для SC-005 провести 10 попыток на заранее отмеченных целях с допуском 12 экранных px и точным совпадением сохранённых координат с маркером.
