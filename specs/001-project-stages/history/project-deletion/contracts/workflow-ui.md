# Workflow UI: одно полотно и контекстные меню

Дополнение FR-039: окончательное удаление самого проекта регулирует [project-deletion.md](project-deletion.md). Прежние удаление объектов плана и очистка остаются по этому документу; они не удаляют запись проекта из каталога.

Дата: 2026-10-12. Приоритетный контракт нового инкремента FR-035–FR-038. Четыре этапа, проверки готовности, сетка, точные размеры и защита вершин остаются. Прежний контракт: [история](../history/vertex-safety/contracts/workflow-ui.md); его списки/пресеты/старый блок угла заменяются правилами ниже.

## Постоянная оболочка

На одном полотне доступны название/адрес, навигация Объект → Плитка → Правила → Варианты, инструменты, статус сохранения, Undo и кнопка меню проекта. На экране одна рабочая панель текущего этапа или выбранного контекста. Меню проекта содержит метаданные, импорт/экспорт и «Очистить проект». Оно не дублирует параметры выбранной стены/комнаты. Переходы сохраняют guards; выбор вершины/стены не стирает выбранное помещение расчёта, но скрывает его настройки.

| Контекст на этапе объекта | Доступные действия |
| --- | --- |
| Ничего не выбрано | Полотно, инструменты, короткая подсказка; без общей формы параметров |
| Вершина | Выделенная точка, переместить/соединить/удалить; без полей «Координата X/Y» |
| Стена | Выделенный сегмент со стрелкой начала → конца; длина участка/исходной цепи, «Выбрать диапазон», направление, относящиеся условия, удалить |
| Диапазон стены | Подсвечены два конца и непрерывная часть исходной стены между ними; после выбора пары — длина, относящееся условие и его действия |
| Помещение | Подсвеченная область, её имя/площадь, размеры для подтверждения и готовность, удалить помещение |
| Отверстие | Подсвеченная граница, удалить отверстие или снять его отметку с разным объяснением последствий |
| Размерное условие | Соответствующая геометрия, значение/fixed, изменить/снять фиксацию/удалить; вычисленный размер не выдаётся за введённое условие |
| Угол | Две стены, узел, выбранная дуга; градусы и действия существующего условия |
| Инструмент | Только его инструкция и относящиеся настройки; никаких списков всей геометрии |

Пресеты «Прямоугольник»/«Г-образное», постоянные нумерованные списки вершин/стен, селекты концов соединения удаляются из UI. В меню стены/вершины нет «Помещение», «Угол сочленения», «Второй луч», «Сектор». Выбор комнаты выполняется на полотне инструментом помещения; её настройки доступны только в её контексте. Числовое создание отдельной новой точки остаётся дополнительным свёрнутым действием «Точное положение» только инструмента добавления; оно не возвращает X/Y выбранной вершины или общую форму. Основной путь — указатель/клавиатурный курсор.

Длины сегмента и исходной цепи обозначаются геометрически, с подсветкой соответствующего диапазона. «Выбрать диапазон» в контексте участка определяет исходную стену: сначала выбрать первый её узел, затем другой узел той же стены. До полной пары поля длины диапазона нет. Чужая вершина или повтор первой дают объяснение и сохраняют первый конец. После пары подсвечиваются оба конца и вся непрерывная часть между ними; начало/конец упорядочиваются вдоль исходной стены, обратный порядок кликов не меняет цель. Escape до применения числа закрывает временный выбор, смена инструмента открывает его контекст; оба действия не меняют geometry/save/Undo. Удаление конца, исчезновение исходной цепи или утрата принадлежности одной цепи сбрасывают выбор и закрывают его меню с возвращением фокуса на доступный canvas control. Только применение положительной длины вызывает setLength; повторный выбор той же пары открывает прежнее условие, в том числе после снятия фиксации, а не создаёт дубликат. Общее условие всей исходной стены остаётся отдельным размером. Готовое условие отменяется обычным Undo. При обычном Undo или замене документа ссылки диапазона проверяются так же, как после команды; дополнительное разделение между сохранёнными концами не сбрасывает его. Списки относящихся размерных условий допустимы только в контексте выбранного объекта, с подсветкой их геометрии. Они не превращаются в общую нумерованную ведомость всех стен/точек. LegacyUnbound остаётся доступным через адресную карточку ошибки.

## Указатель и hit targets

Обычный выбор предпочитает вершину, стену/метку размера, затем внутренность области. Выбор помещения/отверстия использует внутреннюю область, исключая hole rings; для роли void — собственную исключённую область. Инструмент «Угол» принимает только стены: попадание рядом с вершиной не заменяет стену вершиной. При неоднозначном попадании стен в узле нужно выбрать видимую часть стены вне узла; не выбирать первый элемент массива.

Метки размерных условий и дуги являются самостоятельными видимыми hit targets. При наложении меток пользователь может выбрать геометрию и относящееся условие в её контексте; автоматический выбор другой стены не допускается. Диагностика выделяется отдельно от редактируемого объекта, как в FR-034.

Hit области измеряются в CSS px и доступны touch/pen; их прозрачная расширенная область не меняет физические размеры. Клик по панели не проходит к графу, drag/up не создают второй click action. Подсветка hover/focus/selection различима не только цветом. Зона безопасности 12 CSS px действует только для добавления вершины после snap и не блокирует выбор существующей.

## Инструмент «Угол»

| Состояние | Видимый результат и следующий шаг |
| --- | --- |
| Инструмент активирован | «Выберите первую стену», поле градусов отсутствует |
| Первая стена выбрана | Подсветка первой; «Выберите примыкающую стену» |
| Вторая не имеет общего узла или совпадает с первой | Понятное сообщение, первая остаётся выбранной, graph не меняется |
| Две подходящие стены | Подсвечены обе стены и общий узел; две доступные дуги, поля градусов ещё нет |
| Выбрана дуга | Подсвечен конкретный сектор; появляется «Угол между стенами», ° |
| Enter/blur применяет число | Существующий setAngle; entered/fixed различимы от derived; raw с точкой/запятой сохраняется |
| Выбрано уже существующее угловое условие на дуге | Открывается тот же полный контекст пары/сектора; изменить, снять фиксацию, удалить условие |

В узле 3+ стен ни первая, ни вторая не подставляются автоматически. Обе дуги доступны при вогнутом угле; геометрия дуг учитывает ориентацию Y на экране. Допустимы ручные значения строго между 0° и 360°, кроме 180°; 0°/180°/360° показывают ошибку без изменения геометрии. Вычисленный 180° прямой стены отображается как derived и не создаёт ручное fixed-условие; solver проверяет остальные условия по прежним правилам. Отмена незавершённого выбора Escape/сменой инструмента не создаёт Undo/сохранение. После уже применённого числа Escape не отменяет выполненную правку — для неё есть Undo.

## Клавиатура

- Tab входит на один текущий геометрический target полотна и выходит обычным порядком. Фокус виден; SVG представлен доступной интерактивной группой, декоративные линии скрыты от assistive technologies.
- Стрелки в navigation перебирают подходящие текущему инструменту targets в стабильном порядке; Enter/Space выбирает. Accessible label описывает вид объекта, длину/расположение и назначение, без необходимости понимать «стена 4».
- Для «Угла» доступны стены, затем две дуги; стрелки переключают дуги, Enter выбирает, затем можно перейти к градусам.
- Для «Выбрать диапазон» стрелки перебирают узлы выбранной исходной стены, Enter/Space выбирает первый и другой конец; после полной пары Tab переводит в поле длины. Есть подсказка текущего шага и видимый фокус; Escape до применения числа отменяет выбор без правки.
- Для добавления вершины используется видимый курсор: стрелки перемещают на шаг сетки, Shift+стрелки — на 1 мм, Enter добавляет после прежних проверок snap/безопасности.
- Для перемещения Enter на вершине включает preview, стрелки меняют позицию, Enter фиксирует одну команду; Escape оставляет исходную. Координаты могут озвучиваться статусом, но полей selected X/Y нет.
- Для соединения выбрать начальную вершину, затем конечную либо стену. При выборе стены Enter включает курсор точки сочленения на её отрезке; Left/Right перемещают вдоль отрезка на шаг сетки (Shift — 1 мм), с ограничением концами; Enter подтверждает проекцию, Escape отменяет. Без скрытых номерных селектов.
- Числовые/текстовые поля, диалоги и панели не перехватываются shortcuts полотна. Tool change и Escape отменяют незавершённые previews, не меняют завершённый документ.

## Удаление

В контексте каждого типа есть явное действие удаления. Для вершины/стены используется существующее подтверждение каскадных условий с понятной подсветкой. Для комнаты/отверстия сначала read-only preview, затем доступный диалог поверх полотна:

- Выделить всю удаляемую границу и затронутые соседние помещения; отдельно обозначить общие стены и области, которые исчезнут/потеряют подтверждение.
- Объяснить удаление осиротевших граничных точек, условий и записей отверстий; перечисление последствий не подменяет визуальное выделение.
- Кнопки «Отмена» и точное «Удалить помещение»/«Удалить отверстие». Enter не подтверждает до загрузки preview. При изменении исходного графа подтверждение устаревает и запрашивается заново.
- Отмена возвращает прежний объектный контекст и не меняет document/history.
- Успех одной команды одновременно применяет каскад, закрывает меню исчезнувшего объекта, сбрасывает связанные angle/range/connect/move/diagnostic references. Косвенное удаление обрабатывается так же.
- Отказ оставляет объект, меню и объяснение. Сетевой сбой сохраняет intent для явного retry/cancel; частичного удаления не видно.
- После закрытия меню фокус возвращается доступной кнопке инструмента/полотна, а не удалённому SVG target.

После удаления общей стены соседняя незамкнутая область не предлагается для расчёта. Старые варианты/экспорт зависимой области недоступны. Стены вне границы остаются. Удаление отверстия физически убирает его границу; отдельное «Снять отметку отверстия» сохраняет стены и заранее объясняет, что область может стать самостоятельной комнатой. Повреждённый void можно освободить от роли без попытки угадать замкнутую границу.

## Очистка проекта

«Очистить проект» доступна из меню проекта на всех этапах, в том числе при pending/расчёте. Диалог объясняет: будут удалены план, помещения, размеры, плитка, правила, подтверждения и результаты; название/адрес сохранятся; отмена доступна только пока проект открыт в текущей сессии.

Отказ не меняет данные/историю. Подтверждение запускает один whole-document clear, закрывает все меню/выделения, возвращает на пустой Объект и фокусирует доступный canvas control. Статус сохранения отражает реальный результат. Старые ответы не возобновляют состояние. Это относится и к чтению выбранного файла: его позднее завершение или ошибка после clear/Undo clear/закрытия не открывает import preview и не меняет сообщение нового действия.

Undo clear возвращает исходные данные, настройки и подтверждения, но не открывает прежние объектные меню и не запускает pending. Если он восстановлен, показать предложение явно повторить/отменить его. Прежние варианты требуют нового подбора. После закрытия/reload успешно очищенного проекта Undo clear и прежнее подтверждение недоступны.

## Узкий экран и этапы

375 и 1440 CSS px: одна панель поверх полотна с ограниченной высотой и собственной прокруткой; выбранная геометрия/фокус не скрываются полностью. На узком экране используется компактная нижняя панель с явной кнопкой закрытия; камера может перемещаться только для видимости, не для изменения размеров. Горизонтальной прокрутки страницы нет.

Confirmation dialog удерживает фокус и не пропускает действия на полотно; после отмены возвращает фокус на сохранившийся trigger, иначе на canvas control. При переключении этапа transient взаимодействия очищаются, исходные настройки сохраняются. Tile/rules/variants действуют по прежним guards и не показывают чужие object panels.
