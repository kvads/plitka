## Dependencies & Execution Order

```text
Setup (T001–T002)
  └─ Foundation (T003–T009)
       └─ US1 (T010–T018): MVP на существующей геометрии
            ├─ US2 (T019–T025) → US3 (T026–T033)
            └─ US4 (T034–T037)
                 US1 + US3 + US4 → US5 (T038–T042)
                                      └─ Polish (T043–T046)
```

US2 требует интеграции US1, US3 — команд и полотна US2. US4 может разрабатываться после US1 независимо от US2/US3 на сохранённой комнате. US5 использует общие guards с Foundation и базовый подбор US1; полное принятие US5 ждёт геометрические правки US3 и формы US4. Не заявлять все истории независимыми по реализации: независимы их контрольные сценарии на выполненных предпосылках.

Внутри Foundation: T003 → T004 → T005; T003 → T006 → T007; T003 → T008; T005 + T008 → T009. T006 и T008 можно выполнять одновременно с цепочкой документа. Все задачи истории требуют Foundation; её e2e пишутся до реализации и должны сначала показать ожидаемый функциональный отказ. Не запускать ещё не реализованные поздние сценарии как проверку раннего checkpoint.
