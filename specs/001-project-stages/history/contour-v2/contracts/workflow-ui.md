# UI and workflow contract

## Одна рабочая область

Маршрут списка остаётся `/`, проект — `#project/{id}`. Этап хранится в документе, а не выводится из случайного hash-параметра. Постоянны название, адрес, «Все проекты», сохранение/ошибка сохранения, импорт/экспорт проекта и навигация по четырём шагам. Скрытые рабочие области размонтированы; их поля отсутствуют в порядке Tab. Статус шага — derived, сохранённые флаги completed не используются.

| Этап | Видимые средства | Дальнейший переход |
| --- | --- | --- |
| Объект | Сетка, контуры и отверстия, вершины/стены, список размеров и фиксаций, предупреждения, подтверждение вычисленных значений, подтверждение помещения | roomReady |
| Плитка | Сторона квадрата, шов, единицы и ошибки | roomReady + materialReady |
| Правила | Отступ, порог ширины, угол сетки; «Подобрать раскладку» | корректные числовые правила + успешный актуальный подбор с серверной проверкой области после отступа |
| Варианты | Альтернативы, план, метрики, детали, сдвиг/закрепление и экспорты результата | возврат к любому предыдущему шагу |

Сам переход «Далее» не подтверждает вычисленные размеры. В объекте действия «Подтверждаю показанные размеры» и «Подтвердить помещение» явные и разные от обычной навигации. Если все размеры введены/фиксированы, пустой список вычисленных значений не требует лишнего подтверждения. Подтверждение помещения остаётся обязательным.

При возвращении назад из Results текущий результат можно держать в памяти, если исходные данные не менялись. Попытка открыть Results без актуального результата показывает недоступность и путь через Rules, не пустой план. Название/адрес/масштаб/выбор этапа сами по себе не инвалидируют результаты.

## Полотно и привязка

Координаты указателя переводятся в мм через единственную обратную матрицу viewport. Отдельный тип worldPoint не смешивается со screenPoint. Начальный видимый шаг — 100 мм, пользователь может выбрать положительный шаг; масштаб может менять плотность показываемых линий, не геометрию. Привязка проверяется по видимым линиям; подпись шага всегда соответствует им.

Порог привязки — 8 CSS px для мыши, 12 для touch/pen; перевод в мм зависит от масштаба. В пределах порога узла привязать обе координаты. Иначе выбрать ближайшую горизонтальную/вертикальную линию и проецировать только одну координату; вторая сохраняется непрерывной, без округления к узлам. При равном расстоянии линий приоритет вертикальной. За пределами порога оставить свободную позицию. Показать маркер «Узел»/«Линия»/«Свободно» до commit. Числовой ввод обходится без snapping.

Выбор стены показывает стрелку начала/конца, длину и угол именно в конечной вершине; не переопределять начало по направлению перетаскивания. Перемещение вершины на экране — preview до pointer-up, затем ровно одно действие с автосохранением и серверной проверкой. Числовые альтернативы доступны для всех движений.

Диагностика кликом выбирает затронутую стену/вершину. Цвет дополняется знаком и текстом. При изменении длины показать полный набор изменённых вычисленных соседних размеров; пользователь видит форму кандидата до confirm. Неудачный solve не меняет confirmed, сохраняет пользовательский ввод и предоставляет Undo/снятие фиксации.

## Сохранение и сеть

После commit сразу показывается сохранение черновика независимо от геометрической ошибки. Pending solve сохраняется как намерение операции; после перезагрузки его можно повторить, не считать подтверждённым.

При невалидном материале/правилах выводится сообщение у поля без принудительного 0. Десятичные запятая/точка принимаются. «Подобрать» доступна только при выполнении guards; ожидание остаётся на Rules. Guards до запуска проверяют подтверждение помещения и числовой ввод, но не требуют заранее вычисленной области после отступа. Её и лимит ячеек проверяет подбор; ошибка показывается на Rules без потери значений. Пользователь может вернуться назад; ожидаемый ответ после такого перехода не переносит его вперёд.

На Results ручной сдвиг показывает pending состояние; экспорт недоступен до принятого расчёта. При ошибке — оставить последний успешный результат отдельно, предложить повтор или отмену изменения; значения формы и экспортируемый план обязаны соответствовать друг другу.

## Доступность и сохранённые проекты

Навигация — семантические кнопки с aria-current для этапа, причиной недоступности и фокусом на заголовке после перехода. Ошибка числового поля связана через aria-describedby; проблемы объявляются live region без повторов на каждый pointermove. Управление touch не требует hover. При ширине 375 px список шагов переносится/уплотняется, но формы не становятся общим длинным полотном. Поддержать reduced motion и видимый focus.

После открытия старого проекта — Object, размеры вычисленные и неподтверждённые. После загрузки нового документа — восстановить состояние, проверить структуру и geometry, ограничить requestedStage доступностью. Файл не имеет результатов, поэтому saved variants всегда требует нового подбора.
