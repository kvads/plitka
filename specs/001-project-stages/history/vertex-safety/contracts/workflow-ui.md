# Contract: единое полотно, инструменты и четыре этапа

Это целевой контракт графового редактора (FR-001–004, FR-027, FR-030–033). Прежняя версия UI не считается его реализацией.

## Оболочка и размещение

Страница открытого проекта занимает доступную область окна (`100dvh`). ProjectCanvas смонтирован один раз для всех четырёх этапов. Координаты мира в мм, Y инвертируется только в представлении. Метаданные, переходы, сохранение/экспорт и сообщения доступны в закреплённых HTML-меню поверх сцены; отдельного длинного блока параметров над/под полотном нет.

На desktop: компактная верхняя полоса проекта и этапов, палитра инструментов слева, закрываемый инспектор справа, строка статуса снизу. На 375 px: компактная верхняя полоса, кнопка меню этапов/проекта, палитра с подписями, одна выдвигаемая панель поверх нижней части полотна. Панель прокручивается внутри своих границ и закрывается кнопкой/Escape; нажатия через неё не передаются сцене. Активная область числового ввода остаётся доступной при экранной клавиатуре; нет горизонтальной прокрутки страницы. Меню не обязано быть постоянно раскрытым.

Внутри полотна монтируются поля только текущего этапа. Переход сохраняет документ и фокусирует название этапа внутри меню. Навигация показывает активность (`aria-current=step`), завершённость и текст причины запрета. Ни скрытые панели, ни поля другого этапа не входят в Tab.

| Этап | Сцена | Меню |
| --- | --- | --- |
| Объект | весь граф; выбранная область выделена | инструменты, выбор комнаты/отверстия, размеры, общие замеры, диагностика, acknowledgment/confirm |
| Плитка | выбранная комната на фоне плана | сторона плитки, шов, ошибки, назад/далее |
| Правила | выбранная комната, без старого результата как готового | отступ, ширина детали, угол плитки, явный подбор, ожидание/повтор |
| Варианты | актуальная раскладка выбранной комнаты | выбор альтернатив, детали/метрики, сдвиг/lock, экспорт SVG/CSV |

## Инструменты

`Tool = select | addVertex | connect | move | pan | selectRoom`. Одновременно активен один инструмент; выбор инструментов не меняет геометрию и не требует отказа от существующего контура. Новое открытие/смена этапа возвращает безопасный select; незавершённый жест не сериализуется.

- **Выбор**: клик по элементу открывает его инспектор. Числовой список точек/стен и навигация по нему — клавиатурная альтернатива hit-test.
- **Добавление вершин**: клик по свободному месту создаёт независимую вершину. Указание внутри защитной зоны подсвечивает существующую точку и объясняет отказ, не создавая дубликат; подробности в разделе FR-034. Существующие закрытые комнаты не отключают инструмент. Точка на стене сама не создаёт связь; для присоединения используется connect. До commit виден тип привязки.
- **Соединение**: первый клик выбирает существующую вершину, второй — другую вершину или точку на существующей стене. Во втором случае проектируется endpoint на стену и образуется T-узел. После успеха инструмент остаётся выбранным, но начало следующей стены нужно выбрать снова: нет скрытого продолжения от последней точки. Свободное место не создаёт endpoint молча; сообщение предлагает сначала добавить вершину. Выбор той же точки/существующего соединения ничего не дублирует и объясняет причину.
- **Перемещение**: drag вершины — локальный preview до pointer-up, затем одно действие. Весь общий узел движется как одна вершина; связанные условия не снимаются. Новые пересечения после move диагностируются, автоматическое разбиение относится к созданию стены. Координаты доступны в инспекторе.
- **Панорамирование**: жест меняет только viewport; один commit после отпускания. Стрелки меню дают альтернативу drag; масштаб +/- не меняет данные графа.
- **Выбор помещения**: подсветить подходящую замкнутую область под указателем, клик делает её текущей. Список доступных областей в меню даёт клавиатурный выбор. Отдельные точки/висячие стены не являются областью. На границе сначала выбрать соседнюю область из списка, не угадывать сторону.

Добавление заготовки — отдельная команда меню; не очищает существующий граф без явного действия пользователя. Заготовка добавляет свои точки/стены в свободное место, пересечения обрабатываются тем же контрактом. Удаление показывает затронутые стены/размеры; удаление узла с тремя и более стенами удаляет инцидентные участки после явного подтверждения списка, не соединяет произвольных соседей.

## События и привязка

Сцена получает только события, начавшиеся вне меню. Кнопки/поля останавливают распространение pointer-событий; проверяется composedPath. Drag использует pointer capture. Preview, маркеры, подписи и декоративные слои не перехватывают события (`pointer-events:none`). Отпускание после drag не вызывает второй click/add. PointerCancel/Escape/смена инструмента отменяют только незавершённый preview, не удаляют завершённые точки.

Для мыши порог grid snapping 8 CSS px, для touch/pen 12; перевод по обратной SVG-матрице, узел приоритетнее линии, равенство линий разрешается в пользу вертикальной. На линии сохраняется непрерывная вторая координата. В connect сначала ищется существующая вершина в пороге, затем проекция на стену; grid snapping не уводит endpoint со стены. Числовой ввод не привязывается. Подписи, маркеры и hit-target имеют экранный размер, независимый от масштаба мира.

Добавление независимой точки фиксируется на pointer-up при отсутствии drag; сетевой вызов не выполняется на pointermove. На весь command creation + auto-noding приходится один шаг Undo и одно завершённое действие для autosave (запись намерения и затем принятого результата — две записи состояния, не два пользовательских действия).

## Инспектор и размеры

Стена показывает стрелку start→end, длину участка и принадлежность исходной стене. После split отдельно показаны «Общая длина стены» и «Длина участка» с entered/derived. Ввод 1500 для первого участка общей стены 4000 оставляет второй вычисленным 2500; невозможное сочетание не меняет общий замер.

Угол выбирается по двум лучам из общего узла и сектору; подсветка показывает оба участка, дугу и вершину. Условие относится к этому выбору, не к порядковому номеру стены. Прямой угол 180° между частями исходной стены отображается как вычисленный; удалять T/X-узел из-за 180° нельзя. Общая прямолинейность задаётся WallChain, а не пользовательским запрещённым угловым условием 180°.

Ошибки — список внутри меню с кнопкой «Показать», которая выбирает элементы и перемещает обзор; геометрия не меняется. Ошибка локального чужого компонента отображается, но не блокирует независимое выбранное помещение. Вычисленные размеры выбранной комнаты и зависимых общих стен показываются перед отдельным acknowledgment; confirm и «Далее» не заменяют это согласие.

## Готовность и результаты

Использовать guards из data-model.md. При потере выбранной области после split/merge вернуть Объект с просьбой выбрать комнату. Материал/правила сохранены в её прежней записи, но не присваиваются новым областям автоматически. На неизменной области после чистого дробления стен сохранить roomId; новые значения участков требуют перепроверки размеров.

Числовой ввод Enter/blur сохраняется, включая неверный текст; поля показывают единицы и ошибки, связанные aria-describedby. Отступ/gap проверяется численно до запроса, допустимость оставшейся области и лимит ячеек — сервером в явном optimize/layout. После ошибки — тот же этап, тот же ввод, повтор. Назад отменяет автоматическое открытие результатов ожидающим запросом.

Сдвиг имеет accepted/pending; ошибка не заменяет accepted и блокирует экспорт до повтора или явной отмены. Все результаты привязаны к projectId + roomId + inputKey. JSON проекта доступен даже при плохом draft; результаты в него не входят.

## Доступность

Обычные DOM-кнопки, подписи инструментов, aria-pressed, видимый focus, reduced-motion, сообщения статуса только после действия. Меню не перекрывает полностью сфокусированный элемент: панель прокручивается к нему или закрывает мешающий overlay; фокус возвращается на кнопку открытия. Немодальный инспектор не захватывает Tab; действительно модальный импорт удерживает фокус, имеет Escape/отмену и возвращает фокус. Числовые точки, списки начала/конца стены и выбор комнаты позволяют пройти основной сценарий без мыши. Ошибки дополнены текстом и значком, не только цветом.

При конфликте размера можно изменить другое условие, сохранив первое; инспектор показывает весь набор draft, а pending — только последнее действие. Пока не завершены структурная операция/move или legacyPending, доступны их повтор/явная отмена перед следующей геометрической операцией. Поля длины и угла используют общий NumberField с точкой/запятой и точностью ввода 0,1. Снятие фиксации инвалидирует варианты даже без перемещения стен; повторное подтверждение не заменяет новый подбор.

Снятие фиксации после конфликта — размерная операция, доступная без предварительной отмены конфликтующего размерного ввода. reconcile повторяет решение всего набора. После ответа поля сохраняют введённое написание числа, включая запятую; отмена возвращает предыдущее написание.


## Инкремент FR-034: зона добавления и адресная ошибка

В инструменте добавления вокруг каждой вершины виден круг радиусом **12 CSS px**. Круги не масштабируются вместе с геометрией, не зависят от devicePixelRatio и не принимают события. В других инструментах эти круги скрыты. Цвет дополняется контуром и текстом статуса.

Порядок обработки: перевести указатель в координаты плана → применить прежнюю привязку к сетке → перевести итоговую точку и существующие вершины в экранные координаты актуальной матрицей → проверить расстояние <=12 → показать preview → повторить ту же проверку на pointer-up. Матрица/размер overlay обновляются после zoom и resize; при недоступной матрице commit не выполняется. Обрабатываются mouse, touch и pen. Grid snap 8/12 px остаётся отдельным правилом.

При блокировке подсветить адресную существующую вершину и сообщить: «Слишком близко к вершине … Увеличьте масштаб или выберите другое место». Для точного совпадения сообщить «В этой точке уже есть вершина …». Не создавать pending, геометрию, шаг Undo или сетевую команду; инструмент остаётся активным. Preview не должен обещать создание при запрещённом положении. Перекрытие нескольких кругов не вызывает несколько действий. После zoom разные координаты могут оказаться вне круга. Числовое добавление/перемещение сохраняет координаты вне сетки и проверяет совпадение, но не 12 px. Ошибка числового ввода не подменяет введённое значение нулём.

Меню и декоративные круги не пропускают/не перехватывают лишние действия. Escape, pointercancel, смена инструмента и отпускание после drag сохраняют прежние правила без двойного добавления. Текст отказа объявляется доступным статусом после действия, не непрерывно на pointermove.

Карточка zero_wall называет стену, начало, конец и их координаты. При точном равенстве координат сообщает «Координаты концов стены совпадают» и поясняет, что это два разных ID в одном месте. При разных координатах и длине меньше EPS=1e-7 мм сообщает «Длина стены слишком мала», не утверждая совпадения. Выбор сообщения использует точные координаты, а не округлённые подписи. На полотне виден маркер нулевой стены и обоих концов с разнесёнными подписями, без перемещения самих координат. Кнопка «Показать» использует отдельный DiagnosticSelection и очищает прежнее активное редактируемое выделение: сама подсветка ошибки не делает здоровую вершину целью удаления. Редактирование/удаление требует явного выбора элемента обычным способом. Соседние нормальные стены не подсвечиваются как причина. Связанные каскадные ошибки допускается объединить в одну карточку, сохранив возможность увидеть детали и независимые нарушения.

На мобильном экране действие «Показать на плане» закрывает перекрывающую полотно панель и возвращает клавиатурный фокус кнопке «Параметры»; карточку можно открыть повторно. Координаты в карточке отклонённой правки помечены как положение в сохранённом плане, а координаты кандидата остаются в сообщении отказа.
